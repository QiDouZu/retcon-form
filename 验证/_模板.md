# 测试者模板

> 复制这份，填完，放进 `验证\结果\` 目录（文件名随意，`_结果.json` 由进度条脚本读）。
> 一条测试 = 一个文件。**不用写得漂亮，写清"怎么验的、结果是什么"就行。**

---

## 一、你验的是哪条

- 猜想编号：`C__`（见 `_结果.json`）
- 一句话复述（照抄也行）：

## 二、你怎么验的

（一句话：你做了什么、在什么环境、跑了多久）

## 三、结果

- 结论：**支持 / 推翻 / 只验了一部分**
- 证据：命令输出、截图说明、数据、或"我试了 N 次，N 次都是 X"

## 四、什么情况下这个结果不成立

（这条最重要，跟这套格式的规矩一致：你的结论也得写清"怎样才是错的"）

- 例：若某个条件变了，上面的结论可能反过来 → 写出来。
